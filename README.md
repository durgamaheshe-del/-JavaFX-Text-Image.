JavaFX Text and Image Display

Aim

To develop a JavaFX GUI application that displays a text label and an image using an ImageView.

Problem Statement

Create a JavaFX application with a Stage, Label, ImageView and VBox layout.

Requirements

- Window title: Text and Image Display
- Label text: Hello, JavaFX!
- Display an image using ImageView.
- Arrange components vertically using VBox.
- Scene size: 600 x 400 pixels.

Algorithm

1. Import the required JavaFX packages.
2. Create a class named DisplayTextAndImage extending Application.
3. Override the start() method.
4. Create a Label displaying Hello, JavaFX!
5. Load an image from the file path.
6. Create an ImageView and set the image.
7. Create a VBox and add the Label and ImageView.
8. Create a Scene with dimensions 600 x 400.
9. Set the Scene on the Stage and display it.
10. Launch the JavaFX application using main().

Output

The application displays a window titled Text and Image Display with the text Hello, JavaFX! and an image arranged vertically.

Technologies Used

- Java
- JavaFX
- VBox Layout
- ImageView
